# Obsidian 노트 정리 도우미 CLI

> 위클리챌린지 1주차 - CLI 기반 Obsidian 볼트 노트 분석 및 링크 연결 제안 도구

---

## 목표

Obsidian 볼트에서 정리되지 않은 노트를 자동으로 탐지하고, 연관 노트 연결을 제안하는 CLI 프로그램 구현
- `[[링크]]`가 없는 미정리 노트를 재귀 탐색으로 탐지
- 키워드 집합 교집합 기반으로 연결 가능한 노트 제안
- 노트 성격에 맞는 템플릿 구조(학습노트 / 아이디어 / 회고) 제안

---

## 프로젝트 구조

```
week1/
├── main.py    # 메인 실행 파일
└── README.md
```

---

## 실행

```bash
# 실행 후 볼트 경로를 직접 입력
python main.py scan

# 볼트 경로를 옵션으로 바로 넘기기
python main.py scan --vault "/your/obsidian/vault/path"
```

---

## 주요 기능

**`scan` 명령어 흐름**

```
python main.py scan
  └─ 볼트 전체 재귀 스캔
       └─ [[링크]] 없는 .md 파일 목록 출력
            └─ 번호 선택 (input)
                 └─ 파일 내용 출력
                      └─ 연결 가능한 노트 제안 (키워드 기반)
                           └─ 템플릿 구조 제안
```

**링크 제안 출력 예시**

```
[[ 링크 연결 제안 ]]
  1. [[OOP정리]]  (공통 키워드: 클래스, 파이썬)
  2. [[비동기]]   (공통 키워드: async, 파이썬)

[[ 템플릿 제안 ]]
  1. 학습노트
      ## 핵심 개념 / ## 왜 중요한가 / ## 예시·코드 / ## 느낀 점
  2. 아이디어
      ## 아이디어 요약 / ## 배경·동기 / ## 구체화 방안 / ## 다음 액션
  3. 회고
      ## 잘 된 것 / ## 아쉬운 것 / ## 배운 것 / ## 다음에 할 것
```

---

## 회고

평소에 Obsidian을 자주 쓰는데, 노트가 쌓일수록 서로 연결되지 않은 채 방치되는 점이 항상 아쉬웠습니다.  
이번 과제로 그 문제를 직접 해결해보고 싶어 이 주제를 선택했습니다.
현재 구현한 기능은 [[링크]]가 없는 노트를 탐지하고, 키워드 기반으로 연결 가능한 노트를 제안한 뒤, 노트 성격에 맞는 템플릿 구조를 출력해주는 방식입니다.  
이후 자동 분류 및 요약 기능으로 확장할 수 있도록, 구조를 먼저 구현해보고자 했습니다.
또한 pathlib, re, set 같은 파이썬 내장 기능들이 실제로 어떻게 맞물려 동작하는지 직접 따라가며 이해하려고 노력했습니다.  
단순히 검색해서 코드를 가져오는 방식보다 공식 문서와 동작 원리를 읽어보며 구현하는 경험을 해볼 수 있었던 점이 특히 의미 있었습니다.
